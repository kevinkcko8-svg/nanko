ABOUT THE PROJECT

南柯紀事

中國歷史・史料整理與討論

從整理自己的閱讀，到邀請別人一起讀。

本站依「朝代 → 紀 → 紀事 → 小節」編排正文，將參考古籍原文放在對應的小節中。你可以先讀事件，再回頭對照史料，也可以從某一句原文開始提出問題。

目前從西周的篇章起步，持續整理中。這是個人編纂與交流計畫，內容可能仍有疏漏；歡迎附上依據補充、勘誤或提出不同解釋。

如何參與

每篇文章下方都有討論入口。閱讀不需帳號；公開提問與回覆使用 GitHub 帳號。留言不會直接改動正文，整理者可以核對後修訂。

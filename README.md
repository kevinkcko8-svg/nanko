# 南柯紀事｜按小節整理史料版

開啟 `index.html` 即可閱讀。這個版本直接內建使用者提供的完整 JSON 內容，正文與兩筆原有史料都已保留。

## 資料層級

朝代 → 紀 → 紀事 → 正文小標題 → 史料條目。正文小節 `sections[]` 含 `title`、`body` 及 `sources[]`；每一節的史料編號從壹起算，跨節可重複，同節不可重複。

舊版 JSON 格式仍可透過「編輯與備份 → 備份與發布 → 匯入 JSON」匯入。若有舊版紀事層級的 `sources[]`，匯入時會歸到該紀事第一個正文小節（沒有小節時建立「未分類史料」），不會自行猜測應屬於哪個小節。匯入後請自行核對。

## 編輯與發布

「編輯與備份」→「正文與小標題」修改篇名、小節標題與正文；「分節史料」分別在對應小節新增古籍名稱及摘錄原文。切換標籤會保留暫存修改，按「儲存此篇草稿」才會存進當前瀏覽器。

定期在「備份與發布」下載完整 JSON。需要把修改後的資料公開到 GitHub Pages 時，匯出 `data.js`，覆蓋專案原檔並推送更新。此網站不提供帳號或雲端編輯同步。

**注意：** 這版使用新的瀏覽器草稿儲存鍵，以免上一版的舊資料蓋掉本次完整 JSON。若上一版有比此次 JSON 更新的修改，請先從上一版匯出最新 JSON，再於新版手動匯入。
